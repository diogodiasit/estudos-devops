# Estudos DevOps/SRE

Este repositório documenta minha jornada de estudos para me tornar SRE/DevOps. Venho de uma base sólida em infraestrutura (Windows Server, Azure, banco de dados) e estou expandindo pra Linux, containers, Kubernetes e automação. Cada pasta representa um módulo de estudo, com prática real documentada — não só teoria.

## Progresso

- [Fase 01 - Linux](./01-linux/) — navegação, permissões, processos, systemctl, journalctl, apt, manipulação de arquivos
- [Fase 02 - Git](./02-git/) — init, config, branch, merge, .gitignore
- [Fase 03 - Redes básicas](./03-redes-basicas/) — DNS, IP, portas, HTTP/HTTPS, SSH, firewall, load balancer, troubleshooting
- [Fase 04 - Docker](./04-docker/) — containers, imagens, Dockerfile, volumes, docker-compose, Docker Hub, troubleshooting de certificado TLS
- [Fase 05 - CI/CD](./05-cicd/) — GitHub Actions, testes automatizados em Pull Request, branch protection, build e publicação automática de imagem Docker (projeto prático: `projeto-agendamento`)
- [Fase 06 - Azure DevOps](./06-azure-devops/) — Azure Repos, Azure Pipelines, Service Connections, Branch Policies (Build Validation), comparativo com GitHub Actions

## Como uso este repositório

Cada pasta contém arquivos de comandos praticados naquele módulo, sempre com explicação do que cada parte faz — não só "copiar e colar". Progresso gamificado (XP, badges, fases) registrado em PROGRESSO.md.
