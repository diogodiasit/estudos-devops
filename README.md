# Estudos DevOps/SRE

Este repositório documenta minha jornada de estudos para me tornar SRE/DevOps. Venho de uma base sólida em infraestrutura (Windows Server, Azure, banco de dados) e estou expandindo pra Linux, containers, Kubernetes e automação. Cada pasta representa uma semana de estudo, com prática real documentada — não só teoria.

## Progresso

- [Semana 01 - Linux](./semana-01-linux/) — navegação, permissões, processos, systemctl, journalctl, apt, manipulação de arquivos, vim
- [Semana 02 - Git](./semana-02-git/) — init, config, branch, merge, .gitignore

## Como uso este repositório

Cada pasta contém um arquivo `comandos.txt` com os comandos praticados naquela semana, sempre com explicação do que cada parte faz — não só "copiar e colar".
